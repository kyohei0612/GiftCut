# GiftCut 動作確認リスト

リリース前に、人が実際に触って確かめる項目です。

**機械で確かめられるものは、ここに載せていません。** 残っているのは、**目で見ないと分からないこと**と、**耳で聴かないと分からないこと**だけです。

**★** が付いているものは直近で動きを変えた所です。時間が無いときは★だけ回してください。

書き方: 「**やること**」→「**そうなっていればOK**」の順です。

---

## 機械がやってくれること

2つのコマンドが、下のリストに載っていない大半を自動で確認します。

```bash
npm run verify
```

3秒で終わり、編集のたびに自動で走るので飛ばせません。守っているもの:

- 型の食い違い / 時間の計算ずれ（長さ・フレームレート・速度・コマ送り・波形・詰める位置）
- クリップを動かす計算（上書き・空きの掃除・倍速の切り口・まとめて移動）
- リップル削除で詰まる位置が、同じ段のものだけになっていること
- 書き出しの組み立て（名前の付け忘れ、入力番号のずれ、音の無い素材から音を引いていないか）
- 空きを含んだ書き出しが本当に通ること（実際に ffmpeg を走らせて長さまで確認）
- プロジェクトの壊れ（参照切れ、長さ0、番号の重複、段の並び順）
- アプリが起動するか / 起動直後に落ちないか / タイマーや購読の消し忘れ
- OS標準のダイアログ（Windowsの灰色い窓）を一切使っていないこと
- 閉じるときの確認が「閉じない」で閉じず「保存せずに閉じる」でだけ閉じること
- 最近使ったプロジェクトが一覧に出て、選ぶとそのファイルが直接開かれること
- マグネットをボタンで切ると保存され、再起動後も切れたままであること

```bash
npm run e2e
```

本物のアプリを立ち上げ、**実際のマウス操作**で44項目を確認します（`-- --slow` を付けると横で眺められます）。守っているもの:

- 起動して前回の続きを復元し、クリップ・文字・効果音・画像が全部戻ること
- クリップを掴んで動かす、元の場所が空きになる、後ろが動かない、Ctrl+Z で戻る
- 掴んでいる間にブラウザ標準の影と「置けません」が出ないこと
- 離すと丸ごと消えるクリップが、離す前に赤く縁取られること
- 空きをクリックして選び、D で消せる（＝詰まる）こと / 途中に文字があれば手前で止まること
- 空きを掴んでも動かないこと / 同じ素材の断片をイン点で見分けられること
- Alt＝複製、Ctrl＝割り込み、複数まとめて移動
- プレビューの画像を掴むと画像が動くこと（下の動画が動かない）
- クリップは D＝消すだけ（空きが残る）／F＝消して詰める、Delete と Backspace が D と同じ
- C／V／Ctrl+K／Ctrl+A→Delete／Ctrl+Z／Ctrl+Y／Ctrl+Shift+Z／Ctrl+M
- 音量つまみの直後に矢印キーで再生位置が動くこと
- Escape で枠が消える／枠が出ていてもホイールで映像が拡大しないこと
- T キーで文字ができ、埋まっていれば1段上にできること
- トラック名の変更、鍵をかけると動かせないこと
- **ソロにしたまま書き出しても他の音が消えないこと**（書き出して音量を測って比較）
- ドラッグ中にどこでも「置けません」が出ないこと、段の外でも最寄りに置かれること
- 一番下の余白に落としても本編が上書きされないこと
- 素材置き場に戻すと何も置かれないこと
- まだ無い段に落とすとその段と対の音声段が作られること
- 右クリックの色分けと Ctrl+Z、書き出しの解像度が反映されること
- 時刻表示の形式、折りたたみ矢印の記号が揃っていること
- 起動直後の画質設定と、タイムラインが中身の長さに収まっていること
- 素材を追加してもタイムラインに載らないこと／落とした位置から始まること
- 動画を2段目に置くと対の音声段に音が入って連動すること
- 未保存の「＊」が出て、保存すると消えること／最近使ったプロジェクトが増えること
- 字幕（SRT）の読み込み: 件数つきの確認・中止で消えない・置き換えで入れ替わる
- Q での前の編集点まで詰める／文字の手前で止まること
- 波形の帯を掴んでも映像と一緒に動くこと／スペースで再生と停止
- 鍵をかけると長さ変更・分割・削除・複製が全部できないこと（音声側の鍵も含む）
- トラックの追加が番号順に入ること／中身があると削除できないこと／追加を元に戻せること
- 元に戻したあと波形が消えないこと
- 色分けが全種類で効き、本編は映像と音声の両方に付き、「色なし」で戻ること
- お知らせが2件までで、すぐ消えること
- 再生中にカットのつなぎ目で画面が抜けないこと（連写して絵の有無を測る）
- 設定のコピー＆貼り付け（テロップの位置／動画の設定／貼れる種類だけに貼ること）
- 書き出した音に、素材に無い無音ができていないこと／音量が -14 LUFS に揃うこと

## 1. 起動と、前回の続きから始める

- [ ] 「破棄して新規」を押す → 前回の内容がどこにも残っていない
- [ ] 保存したファイルを開く → 閉じる → もう一度開く → まったく同じ状態になっている

## 2. 保存と、別のプロジェクトへの切り替え

- [ ] ★ 保存した直後に×ボタンで閉じる → 警告が出ずにそのまま閉じる
- [ ] ★ 何か編集して保存せずに「プロジェクトを開く」を選ぶ → 確認が出て、「中止して保存する」を押すと何も変わらない
- [ ] ★ 動画がある状態で「動画を差し替え」を選ぶ → 確認が出て、「差し替える」で差し替わる
- [ ] ★ どの確認画面もEscキーで中止できて、裏のタイムラインが勝手に動かない
- [ ] ★ 一覧のファイルを別の場所へ移動してから選ぶ → エラーが出て、その項目が一覧から消える

## 3. 素材の取り込みと配置

- [ ] ★ 1本目の動画も、落とした場所から始まる（勝手に先頭に置かれない）
- [ ] Ctrlを押しながら落とす → 割り込みで入り、後ろにあったものが後ろへずれる
- [ ] 動画をドラッグしている間、置く予定の場所に半透明の影が出て、音の波形も見えている
- [ ] ★ 文字が入っている段に動画を置く → 文字が1段上へ避難し、避難先の段が元の段より前面に表示される
- [ ] 画像を置ける。ドラッグで動かせて、端をつまんで長さを変えられて、カッターで切れる
- [ ] ★ 左のトラック名の列やメニューバーの上でも「置けません」のマークが出ない
- [ ] ★ 画像や音声をプレビュー画面へ落とす → タイムラインの一番近い場所に置かれる

## 4. カットと、クリップを動かす

- [ ] ★ Wキーで、次のカットまで削って詰める
- [ ] ★ 文字が無い場所でQキーを押す → いつも通りカットまで詰まる
- [ ] クリップを消したあと、文字・効果音・画像・重ねた動画も一緒にずれる（バラバラにならない）
- [ ] ★ 掴んだ後で途中からAltやCtrlを押しても、切り替わる（枠の中の文字が「移動」「複製」「割り込み」と変わる）
- [ ] ★ Ctrlを押して動かさずにクリックだけする → これまで通り、複数選びの追加・解除になる
- [ ] ★ Ctrl+Aで全部選んでから本編のクリップを動かす → 文字・効果音・画像・重ねた動画・目印も一緒に同じだけ動く
- [ ] ★ 全部選んで動かしている途中でAltかCtrlを押す → 文字などが元の位置に戻る
- [ ] ★ 空きにマウスを乗せると、うっすら枠が出て「触れる場所」だと分かる
- [ ] ★ 詰めきれない空きをもう一度消そうとすると「この空きの先頭には別のクリップが来ています」と出る
- [ ] ★ 空きが入ったまま書き出す → 空きの間は黒い画面と無音になり、全体の長さが合っている
- [ ] ★ 空きが入ったまま保存して開き直す → 空きがそのまま残っている
- [ ] 速度を2倍にしたクリップの右端をつまんで左右に動かす → つまんだ端がマウスカーソルからずれていかない

## 5. 選ぶ操作とキー操作

- [ ] ★ 重ねた動画を選んだあと、本編のクリップをクリックしてDeleteを押す → 本編だけが消える
- [ ] ★ 効果音を複数選んでドラッグする → 選んだ全部がまとめて動く
- [ ] ★ 画像と重ねた動画でも、複数選んでまとめて動かせる
- [ ] ★ 左の素材置き場で素材を選んでDeleteを押す → 素材置き場のものが消える

## 6. プレビュー画面での直接操作

- [ ] ★ プレビューに出ている「重ねた動画」も掴んで動かせる
- [ ] ★ 画像も重ねた動画も無い所を掴む → これまで通り、本編の映像を動かす操作になる
- [ ] ★ 掴んだものの上にマウスを置くと、名前が吹き出しで出る

## 7. 文字（テロップ）

- [ ] 文字を分割する → 左右それぞれが自然に見える（分け目で一瞬消えたりしない）
- [ ] 色を変える → その色に割り当てたアイコンが反映される
- [ ] プレビューの文字をダブルクリックする → その場で文字を打ち直せる
- [ ] 見た目のテンプレートを変えても、位置とアニメが保たれる。手順は、まず文字を1つ作り、プレビュー上でドラッグして画面の左下へ動かし、アニメを1つ付けてから、別の見た目のテンプレートを選ぶ。最初から何も変えていないと違いが見えないので、必ず先に位置とアニメを変えること

## 8. 重ねた動画（ワイプ・PiP）

- [ ] ★ 拡大、透け具合、回転、上下反転、明るさなどの色味、切り抜きが全部設定できる
- [ ] ★ 「変形・調整をリセット」を押す → 設定した項目が全部元に戻る
- [ ] ★ 選んだ状態でプレビューの上でマウスホイールを回す → 拡大縮小できる
- [ ] ★ 拡大のつまみを右端まで動かすと800%まで行く（ホイールと同じ上限）
- [ ] 音の波形が映像とずれずに並んでいる
- [ ] 音量、だんだん大きく、だんだん小さく、が効く

## 9. 音（聴いて確かめる）

- [ ] ★ 再生位置の縦線と、音の波形の山がぴったり合っている。特に素材の後半で確認する
- [ ] ★ 画質設定を切り替えても、波形の位置がずれない
- [ ] ★ ミキサーの数字に「dB」が付いている
- [ ] ★ 効果音の音量つまみが、他の画面のつまみと同じ細かさで動く
- [ ] トラックのミュート（Mボタン）が、再生と書き出しの両方に効く
- [ ] 書き出した動画を再生して、音が途切れない。全体の音量が揃っている

## 10. リップル削除（消して後ろを詰める）

- [ ] ★ 画像と重ねた動画でも同じように詰まる（これまでは文字しか詰まらなかった）
- [ ] ★ 上から2段目の文字をリップル削除する → 3段目の文字は動かない
- [ ] ★ 鍵をかけた段のクリップが選択に混ざっていると、実行されずに理由が表示される
- [ ] ★ 文字と効果音と画像をまとめて選んでリップル削除する → それぞれが自分の段の中だけで詰まる

## 11. トラック（段）

- [ ] ★ 一番下の映像の段に鍵をかける → 動画を落としても本編が上書きされない

## 12. 元に戻す・やり直す

- [ ] カット、分割、削除、複製が、Ctrl+Zで戻る
- [ ] 元に戻す→やり直す、をしても素材が入れ替わらない

## 13. 書き出し（見て・聴いて確かめる）

- [ ] ★ 画面上の「書き出し」を押す → いきなり書き出しが始まらず、設定画面が出る
- [ ] ★ フレームレートを「素材と同じ」にして書き出す → 元の素材と同じなめらかさになる
- [ ] 画質の設定が、できあがりに反映されている
- [ ] 文字・画像・重ねた動画・効果音が全部合成されている
- [ ] カットのつなぎ目のじわっと切り替わる効果が、指定した長さで入っている
- [ ] 書き出しの途中でキャンセルできて、中途半端なファイルが残らない
- [ ] 文字を100枚以上入れたプロジェクトでも書き出せる

## 14. 見た目・表示

- [ ] ★ フレームレートの表示に、スペースが入っているものと入っていないものが混ざっていない
- [ ] ★ 「移動しました」のような、見れば分かる操作でお知らせが出ない
- [ ] タイムラインを拡大縮小しても、クリップの位置がずれない
- [ ] トラックを増やしても、縦にスクロールすれば全部見える

## 15. クリップの色分け

- [ ] ★ 色を付けたまま保存して開き直す → 色が残っている

## おかしいところを見つけたら

1. **どの操作で起きたか**をメモする（キーを押したのか、クリックしたのか、起動直後だったのか）
2. ターミナルで `npm run check` を実行して、プロジェクトが壊れていないか確かめる
3. 書き出しに関する問題なら、設定の記録が `userData/last-export-filter.txt` に残っている

直したあとは、**同じ間違いが二度と通らないようにテストを足す**こと。`npm run e2e` に足せるものはそちらへ足して、この一覧からは消してください。
