# GiftCut 動作確認チェックリスト

リリース前に人が触って確かめる項目。**自動テストで守れないものだけ**を載せている。

自動で守っているもの（`npm run verify` が3.6秒で実行、編集のたびに自動実行される）:

- 型の不整合
- 時間計算のズレ（尺・fps・速度・フレーム・波形・リップルの停止位置）
- 書き出しのフィルタグラフ（ラベルの定義漏れ、入力indexのズレ、無音素材からの音声参照）
- プロジェクトの整合性（参照切れ、長さ0、id重複、トラックの並び順）
- アプリが起動するか／起動直後の処理で落ちないか／タイマーと購読の解除漏れ

ここに載っているのは、**操作の連鎖**と**目で見ないと分からないこと**。

凡例: **★** = 直近で挙動を変えた所（時間が無いときは★だけ回す）

---

## 1. 起動と復元

- [ ] アプリが起動して、前回のプロジェクトの復元プロンプトが出る
- [ ] 「復元する」で、テロップ・カット・SE・画像・映像レイヤーが全部戻る
- [ ] 「破棄して新規」で、前のプロジェクトの内容が残っていない
- [ ] ★ マグネット（磁石アイコン）を切って再起動 → **切れたまま**になっている
- [ ] ★ プレビュー解像度が「原本（最高画質）」で始まる
- [ ] 保存済みプロジェクトを開いて、閉じて、開き直す → 同じ状態になる

## 2. 保存とプロジェクトの切り替え

- [ ] ★ 新規プロジェクトを保存した直後、タイトルの「\*」が消える
- [ ] ★ 保存した直後に ✕ で閉じる → **「保存していない変更があります」が出ない**
- [ ] ★ 何か編集して保存せずに「プロジェクトを開く」→ **確認が出る**
- [ ] ★ その確認で「キャンセル」→ 何も変わらない
- [ ] ★ テロップがある状態でSRTを読み込む → **件数を示す確認が出る**
- [ ] ★ その確認で「キャンセル」→ テロップが消えていない
- [ ] ★ クリップを動かした直後に Ctrl+S → Ctrl+Z で**その移動が**取り消される

## 3. 素材の追加と配置

- [ ] 動画を追加してもタイムラインに勝手に置かれず、プロジェクトに溜まる
- [ ] ビンからタイムラインへドラッグ → 落とした位置から始まる
- [ ] Ctrl を押しながらドロップ → 挿入配置になる（後ろがずれる）
- [ ] 動画をドラッグ中、ゴーストに**映像と音声の両方**が出て、波形も見える
- [ ] V3 に動画を置くと A3 に音声が入り、位置が完全にリンクする
- [ ] ★ V2 にテロップがある状態で V2 に動画を置く → テロップが上の段へ退避し、
      その段が **V3 より上**に表示される（番号が大きいほど前面）
- [ ] 画像を置ける。ドラッグ・トリム・レザーで分割できる

## 4. カット編集

- [ ] `C` でレザー、`V` で選択ツールに戻る
- [ ] ★ `Ctrl+K` で再生ヘッド位置に編集点が入る（旧 `W`）
- [ ] ★ `Q` で前の編集点まで詰めて削除（旧 `A`）
- [ ] ★ `W` で次の編集点まで詰めて削除（旧 `F`）
- [ ] ★ **テロップの上で `Q`** → カット点まで一気に消えず、**テロップの手前で止まる**
      （テロップが巻き添えで消えない）
- [ ] ★ テロップが無い区間で `Q` → 従来どおりカット点まで詰まる
- [ ] ★ `D` と `Delete` と `Backspace` が同じ動作になる
- [ ] クリップを削除したあと、テロップ・SE・画像・映像レイヤーが**一緒にずれる**
- [ ] 速度を 2倍 にしたクリップでトリムしても、掴んだ端がカーソルに追従する

## 5. 選択とキー操作

- [ ] ★ 映像レイヤーを選んだあと本編クリップをクリック → Delete で**本編だけ**消える
      （映像レイヤーが巻き添えにならない）
- [ ] ★ マーカーを選んだあと本編クリップをクリック → Delete で**本編が**消える
      （マーカーだけ消えるのは誤り）
- [ ] ★ `Ctrl+A` → `Delete` で全部消える（「トラックは削除できません」で止まらない）
- [ ] ★ 音量スライダーを触った直後に矢印キー → **再生ヘッドが動く**（スライダーではない）
- [ ] ★ 同じくスペースキーで再生が始まる
- [ ] ★ プレビューをクリックしてリフレーム枠が出た状態で `Escape` → **枠が消える**
- [ ] ★ 枠がある状態でタイムライン上をホイール → 映像が拡大されない
- [ ] ★ SEを複数選んでドラッグ → **選んだ全部が**まとめて動く
- [ ] ★ 同じく画像・映像レイヤーでもまとめて動く
- [ ] ★ 素材ビンで素材を選んで Delete → **ビンの素材が**消える
      （タイムラインのクリップが消えるのは誤り）

## 6. テロップ

- [ ] ★ 何も無い所で `T` → **V2** にテロップができる
- [ ] ★ V2 にテロップがある位置で `T` → **1段上**にできて、その旨のトーストが出る
- [ ] テロップを分割すると、左右それぞれ自然に見える（途中で一瞬消えない）
- [ ] テンプレートを適用しても位置とアニメが保たれる
- [ ] ラベル色を変えると、色に割り当てたアイコンが反映される
- [ ] プレビューでダブルクリック → その場で文字を編集できる

## 7. 映像レイヤー（PiP）

- [ ] ★ 拡大・不透明度・回転・**上下反転**・**色調整**・**クロップ**が全部設定できる
- [ ] ★ 「変形・調整をリセット」で、設定した項目が全部戻る
- [ ] ★ 選択してプレビューでホイール → 拡大縮小できる
- [ ] ★ 拡大スライダーを右端まで動かすと **800%** まで行く（ホイールと同じ上限）
- [ ] 音声帯の波形が映像とずれずに並ぶ
- [ ] 音量・フェードイン・フェードアウトが効く

## 8. 音声

- [ ] ★ 再生ヘッドと波形の山が**ぴったり合う**（特に素材の後半）
- [ ] ★ プレビュー解像度を切り替えても、波形の位置がずれない
- [ ] ★ ミキサーの数値に **dB** が付いている
- [ ] ★ SEの音量スライダーが、他のパネルと同じ細かさで動く
- [ ] トラックのミュート（M）が再生と書き出しの両方に効く
- [ ] ★ **ソロ（S）にしたまま書き出す** → 他のトラックの音が**消えていない**
      （ソロはモニター専用。ここが一番損害の大きい事故）

## 9. トラック

- [ ] ★ トラック名を**ダブルクリックで変更**できる
- [ ] ★ トラック名をクリックしても青く光るだけの表示が出ない（ターゲット廃止）
- [ ] ★ トラックをロックすると、以下が**全部**できなくなる:
  - [ ] ドラッグ・トリム・レザー分割
  - [ ] Delete での削除
  - [ ] クリップの **✕ ボタン**
  - [ ] **Ctrl+D の複製**
  - [ ] **右パネルのプロパティ変更**（音量・不透明度・色調整など）
  - [ ] 他のレーンからその段へドラッグして入れる
- [ ] ★ **A1 をロック**すると、本編の波形をレザーで切れない／Delete で消せない
- [ ] ★ **V1 をロック**すると、動画をドロップしても本編が上書きされない
- [ ] トラックを追加すると、番号順の正しい位置（映像は上、音声は下）に入る
- [ ] 中身のあるトラックは削除できず、理由が表示される

## 10. Undo / Redo

- [ ] カット・分割・削除・移動・複製が Ctrl+Z で戻る
- [ ] Ctrl+Y（または Ctrl+Shift+Z）でやり直せる
- [ ] Undo したあと、波形が消えない
- [ ] Undo → Redo で素材が入れ替わらない
- [ ] トラックの追加・削除が Undo で戻る

## 11. 書き出し

- [ ] ★ モードバーの「書き出し」で**設定ダイアログが出る**（即書き出しが始まらない）
- [ ] メニューの「動画を書き出し…」と `Ctrl+M` でも同じダイアログが出る
- [ ] ★ fps「素材と同じ」で書き出すと、元素材と同じ fps になる
- [ ] 解像度・画質（CRF）の設定が反映される
- [ ] テロップ・画像・映像レイヤー・SE が全部合成されている
- [ ] 音が途切れない。全体の音量が揃っている（ラウドネス）
- [ ] クロスディゾルブが指定どおりの長さで入る
- [ ] 書き出し中にキャンセルできて、中途半端なファイルが残らない
- [ ] 素材の数が多い（テロップ100枚以上）プロジェクトでも書き出せる

## 12. 表示

- [ ] ★ ルーラーの目盛りと再生ヘッドの時刻表示が**同じ形式**（`00:01:23:12`）
- [ ] ★ fps の表記にスペースの有無が混ざっていない
- [ ] ★ 左パネルと右パネルの折りたたみ矢印が同じ記号
- [ ] タイムラインを拡大縮小しても、クリップの位置がずれない
- [ ] トラックを増やしても、縦スクロールで全部見える

## 見つけたら

1. **どの操作で起きたか**を書き留める（キーか、クリックか、起動直後か）
2. `npm run check` を実行してプロジェクトの不整合を確認する
3. 直近の書き出しの問題なら `userData/last-export-filter.txt` に合成設定が残っている

不具合を直したら、**同じ型を二度と通さないためのテストを足す**こと。
このチェックリストの項目が自動で守れるようになったら、ここから消してよい。

## 13. ラベルカラー（新機能）
- [ ] ★ 動画クリップを右クリック → 色を選ぶとクリップ全体がその色になる
- [ ] ★ テロップ・画像・SE・映像レイヤーでも同じように色を付けられる
- [ ] ★ 本編の映像と音声は同じクリップなので、片方に色を付けると両方に付く
- [ ] ★ 「色なし」を選ぶと元の色に戻る
- [ ] ★ 色を付けたまま保存して開き直す → 色が残っている
- [ ] ★ 色を付けてから Ctrl+Z → 色が戻る
