# GiftCut

切り抜き動画を作るための、テロップ編集アプリ（Windows）。

汎用の編集ソフトを目指していません。**切り抜きで毎回やる作業を速くする**ことだけに寄せています。

## できること

| | |
|---|---|
| テロップ | 縁取り・影・グラデーション・部分装飾。テンプレートとして保存して使い回せる |
| 動き（キーフレーム） | テロップも動画クリップも、時間で 拡大・位置 が変わる。「話者にシュッと寄る」がそのまま作れる |
| 無音カット | 喋っていない所をまとめて切る。切る前に「◯か所・合計◯秒」を出す |
| BGM ダッキング | 声が入っている間だけ BGM を下げる。**プレビューと書き出しで同じ音になる** |
| 書き出し | GPU（NVIDIA / Intel / AMD）で焼く。使えない機械では自動で CPU に落ちる |
| 素材の持ち出し | 素材ごと1つの ZIP にまとめて、別の PC で開ける |
| 画面 | 各パネルを別ウィンドウ・別モニターへ出せる |

## 入れ方

[Releases](https://github.com/kyohei0612/GiftCut/releases) から
`GiftCut Setup x.x.x.exe` を落として実行してください。

**「Windows によって PC が保護されました」と出たら、`詳細情報` → `実行` で入ります。**
コードサイニング証明書（有料）を取っていないため出る警告で、中身の問題ではありません。

一度入れれば、次からは**起動時に新しい版を見つけて勝手に更新します**。
書き出し中や、保存していない編集があるときは再起動しません。

## 同梱している物について

動画の読み込みと書き出しに [FFmpeg](https://ffmpeg.org/) を使っています（LGPL v3）。
表示とライセンス本文は [`licenses/FFmpeg/`](licenses/FFmpeg/) にあります。
アプリのフォルダの中にも同じものが入っています。

効果音とテロップの素材集は**同梱していません**（再配布が許可されていないため）。
手持ちの物を使う場合は、`%APPDATA%\GiftCut\` の下に `SE\` `telop-presets\` として置けば読み込まれます。

## 開発

```bash
npm install
npm run dev                 開発中の起動
npm run verify              型と単体テスト（コミット前に自動で走る）
npm run e2e                 通しの動作確認（約185項目）
npm run walk                使用感チェック
npm run bench               負荷と限界の測定
npm run dist                インストーラを作る
npm run check:packaged      配布物が本当に動くかを確かめる
```

確認の作り方について、この作業で繰り返し効いた考え方が2つあります。

- **「できない」を確かめる前に、まず同じ操作が「できる」ことを確かめる。**
  操作が届いていないだけでも合格してしまうため
- **直したときは、直す前に戻して落ちることを1回確かめる。**
  確認そのものが空振りしていないかは、それでしか分からない
